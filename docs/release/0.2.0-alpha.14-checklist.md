## 清单

1. **升级与承载** —— 插件管理升级到 `0.2.0-alpha.14` 成功；输入区接管卡正常出现。
2. **模型 pill 行结构（#39 复测）** —— **反转消失**：窗宽较大时 pill 稳定显示「模型名 · 思考强度」，逐像素拖动窗宽无抖动翻转；行更紧时先没思考强度、再折叠纯 icon（模型名不再以截断形态「假展开」）；hover 提交钮期间 pill 形态不翻转；模式钮 22px、提交钮 34px 不变。**如实记录**：与原生完全同阈仍差 ≈28px 结构盈余（模式座位），清零属产品决策。
3. **dock 行三件套（#43 复测）** —— 量表行从左到右：会话统计 pill（表盘图标 `N 轮 M 步 · X tok/s`）+ token 用量 pill（数据库图标 `Y tok · 缓存命中 Z%`）+ 上下文量表环（与原生同序同形，深浅主题）；数值与原生栏同会话一致；**空白会话只有量表无 pills**；无投影/无数据的 pill 独立隐藏；已知偏差：detailed 模式下原生 pill 可点开统计对话框，本版为静态呈现。
4. **添加工作区（#42 复测）** —— 工作区菜单底部出现「添加工作区…」行（加号图标、脚注分隔线）；点击 → **OS 目录选择器**弹出 → 选定后新建工作区并自动切换；非法路径/名称冲突 → 卡顶横幅「无法打开文件夹：…」+「重新选择」按钮重拉流程；流程进行中菜单行 disabled；**空列表时点 chip 直接拉起 OS 流程**（不出空菜单）；取消选择静默关闭；宿主词典缺失时兜底文案仍为原生同款。
5. **IME 组合提交（#45 复测）** —— 中文输入法：`/` → 根列表；IME 键入 `mo` → Enter 提交组合 → 弹层**立即切换到 `mo` 预匹配并预选**；组合进行中弹层保持根列表不闪烁；英文直键路径不回归；`@` 文件弹层用 IME 同样验证；Escape/点外关闭不回归。
6. **回归不丢** —— alpha.13 已通过项不回退：hero 同行与预设菜单（本地化名+描述+勾选）、量表行位置、卡面背景与拖放、todo 面板、feedback 行、链式弹卡、编辑手感、实时渲染、排队/停止/附件粘贴、气泡渲染、停用回落。
