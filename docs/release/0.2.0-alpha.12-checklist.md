# 0.2.0-alpha.12 发布验收清单

- 版本: `dsh-markdown-input@0.2.0-alpha.12`
- 内核线: `@deepseek-ai/dsh` `0.2.0-rc.x`（桌面端 `0.2.0-rc.2` 内核）
- 依据: [ADR-0004](../adr/0004-npm-release-remote-feedback-loop.md)、[ADR-0006](../adr/0006-hero-seats-in-card-rebuild.md)
- 性质: **alpha.11 体验轮反馈汇总（七票）** —— 弹层语义两票（#35 #36）、工具行与圆角/命中区三票（#39 #40 #41）、三处被接管结构性隐藏的原生座位重建（#38 todo、#43 上下文量表、#42 hero 工作区行 + Agent 预设）
- 验收基准: 条目与 [alpha.11 清单](0.2.0-alpha.11-checklist.md) 相同；第 4–9 条为本轮七票的复测主项，第 10 条为停用回落与既有主项不回归
- 记录: 结果写入 `outputs/retest-YYYYMMDD-alpha12.md`；确认的缺口就地开 issue

## 清单

1. **搜索与升级** —— 官方桌面端插件管理 UI 能搜到 `dsh-markdown-input`，升级到 `0.2.0-alpha.12` 成功；输入区变为接管卡。
2. **编辑手感** —— 编辑器可输入，焦点、中文输入法、Enter 发送 / Shift+Enter 换行正常；草稿跨页面刷新幸存。
3. **实时渲染** —— 粗体/斜体/行内代码/删除线以真样式呈现、语法标记淡显；光标行保留标记、移开折叠；渲染/源码开关可用。
4. **`+` 菜单 feedback 行直达反馈对话框（#35）** —— `+` 菜单与 `/` 补全弹层的 feedback 行点击**立即打开原生反馈对话框，草稿无任何插入**；手打 `/反馈 文本` 回车仍按 claim 提交（原生 typed remark 路径）；宿主未组合 `ui-message-feedback` 时该行退化为原 claim 行（不消失、不报错）。
5. **链式弹卡选成功消费触发 token（#36）** —— 输入 `/mo` → 弹层 model 行 → 选模型成功 → **草稿里 `/mo` 被清除**且焦点回到编辑器；选模型失败（writer-held 提示）token 保留；开卡后 Escape / 点外部关闭 token 保留；直接点 pill 开卡选择不动草稿；permission 链同语义；`+` 菜单路径（无草稿 token）行为不变。
6. **工具行图标化与行预算（#39）** —— 原生会显示模型名的窗宽下，接管卡 pill **同样显示模型名**（不再折成纯 icon）；提交钮为原生同款纯图标圆钮（含停止态方块 glyph），tooltip/aria 正确（停止态 tooltip=停止）；模式切换钮为纯图标、功能/持久化/locale 文案跟随语言不变；可续子会话专属方形停止钮不受影响。
7. **圆角与命中区（#40 #41）** —— 卡片四角与原生输入卡同等圆润（深浅主题），拖放遮罩在卡角不露角；点占位符行以下的空白区可聚焦、光标落在末行末尾；点卡内空白（padding、条带间隙）聚焦编辑器；点工具行按钮/弹层/附件芯片不抢焦点；编辑器内选择文本、IME 组合不受影响。
8. **todo 面板与上下文量表（#38 #43）** —— 会话产生 todo 后，输入条上方出现 todo 面板（**在目标栏之前**），进度与条目内容同原生一致、折叠/展开同原生、无 todo 时不出现；接管卡**正下方**出现上下文量表的圆环 + 百分比（与原生同位同形，深浅主题），点击开构成面板（分段/明细/紧凑数字同原生），无投影或无容量时完全不渲染，模型切换致容量暂失时面板自动关闭。
9. **新会话 hero 座位（#42）** —— 新会话（空白会话）卡顶出现**工作区 chip + Agent 预设控件**，老会话不出现；chip 标签五级解析链同原生，点击弹工作区列表（当前勾选、无「添加工作区」行），选定后在该工作区复用/新建空白会话并切换；无可解析工作区时**整卡虚线触发姿态**（不可输入、整卡点击弹菜单、placeholder 同原生），选定后恢复可输入；Agent 预设可查看当前值、roster 菜单可切换（宿主拒绝就地横幅），数据面缺席时该面隐藏；触发姿态与菜单键盘可达（Enter/Space 开、Escape 关）；**第一条消息仍在接管卡内发送**。
10. **回归不丢** —— 计划 chip 与目标栏（#34）、排队消息栏与撤回/编辑、发送/停止/排队、附件与富文本粘贴、`@`/`/` 弹层与 chip、气泡 Markdown 渲染与复制操作行（#33）全部不回退；停用（或移除）插件后回落原生输入区与气泡，重新启用后接管卡回归。
