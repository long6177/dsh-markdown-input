# 0.2.0-alpha.9 发布验收清单

- 版本: `dsh-markdown-input@0.2.0-alpha.9`
- 内核线: `@deepseek-ai/dsh` `0.2.0-rc.x`（桌面端 `0.2.0-rc.2` 内核）
- 依据: [ADR-0004](../adr/0004-npm-release-remote-feedback-loop.md)；[ADR-0005](../adr/0005-composer-revival.md)
- 性质: **model 弹卡链路修复** —— alpha.8 真机复测确认 claim 行修复，但 model 行鼠标点击无反应（Enter 正常）。根因：vendored 模型卡外部关闭监听挂 document **mousedown**，而链路从菜单行 mousedown 派发中开卡，监听挂上时当次 mousedown 仍在冒泡 → 卡片开后 ~1ms 自关（绘制之前；jsdom 无法复现该竞争，真实 Chromium harness + Playwright 物理指针复现）。`+` 菜单 model 行鼠标路径同病灶（alpha.6「`+` 菜单正常」实为键盘观察）。修复：外部关闭 mousedown → **pointerdown**（对齐原生 popupSelect 家族），真实浏览器四链路复验通过
- 验收基准: 条目与 [alpha.8 清单](0.2.0-alpha.8-checklist.md) 相同；第 8 条 model 行为 #28 复测主项。feedback 行语义缺口（原生直达对话框不插 token）已转 #35，不在本版

## 清单

1. **搜索与升级** —— 官方桌面端插件管理 UI 能搜到 `dsh-markdown-input`，升级到 `0.2.0-alpha.9` 成功；输入区变为接管卡。
2. **编辑手感** —— 编辑器可输入，焦点、中文输入法、Enter 发送 / Shift+Enter 换行正常；草稿跨页面刷新幸存。
3. **实时渲染** —— 粗体/斜体/行内代码/删除线以真样式呈现、语法标记淡显；光标行保留标记、移开折叠；渲染/源码模式开关可用。
4. **`+` 命令菜单** —— goal/plan 插入 claim token 后回车正确触发；**permission/model 行用鼠标点击链式打开第二层弹卡**（本轮修复点，勿再用键盘验证）。
5. **权限与模型 pill** —— 权限预设三档切换生效、完全权限有确认门；模型/推理等级切换生效。
6. **发送/停止/排队** —— 运行中空草稿主钮变「停止生成」、点击中断在气回合、停止后回落「发送」；排队条目可见、撤回/编辑/改向正常。
7. **附件与粘贴** —— 附件上传/移除正常；富文本粘贴转干净 Markdown，`Ctrl/Cmd+Shift+V` 纯文本直插。
8. **补全弹层（#28 复测主项）** —— 输入 `/` 弹出补全弹层：**model 行鼠标点击打开模型选择弹卡**（本轮修复主项；Escape 可关、点外部可关、选模型生效）；**claim 行（计划/目标/反馈）点击插入 token**（alpha.8 已过，回归确认）；技能行选中插入、file 行附件选择、compact/export 直达执行回归正常；`@` 文件搜索与 Tab 下钻正常。feedback 行语义偏差（插 token 而非开对话框）为 #35 已知项，不阻塞。
