# 0.2.0-alpha.1 发布验收清单

- 版本: `dsh-markdown-input@0.2.0-alpha.1`
- 内核线: `@deepseek-ai/dsh` `0.2.0-rc.x`（桌面端 `0.2.0-rc.2` 内核）
- 依据: [ADR-0004](../adr/0004-npm-release-remote-feedback-loop.md)
- 性质: **rc.2 兼容修复版** —— 0.2.0-alpha.0 在 rc.2 桌面端因 primitives 图标改名（`*Outline16` → `*OutlineMedium`、`DocumentFileIcon` → `FileTypeIcon`）导致接管组件渲染崩溃、输入区整体消失；本版对齐 rc.2 实际 API
- 说明: 清单与 0.2.0-alpha.0 相同，需在桌面端全部重验

## 清单

1. **搜索与安装** —— 官方桌面端插件管理 UI 能搜到 `dsh-markdown-input`，安装/升级到 `0.2.0-alpha.1` 成功。
2. **实时渲染** —— 输入区变为 Markdown 实时编辑器：光标所在行语法标记可见，移开后折叠为样式呈现。
3. **模式切换** —— 渲染/源码模式可切换，重启会话后仍记住上次的模式。
4. **发送保真** —— 发送后模型收到的仍是原始 Markdown 源码（渲染只是视觉层，不改变提交内容）。
5. **用户消息投影** —— 已发送的用户消息在聊天记录中按 Markdown 渲染，渲染不破坏消息内容（若消息内含宿主侧产生的引用 chip，chip 不被画坏；真机勘误：v1 输入区不提供 @提及/技能 chip 的输入入口，本条仅考察投影渲染）。
6. **粘贴转换** —— 粘贴富文本自动转为干净 Markdown；`Ctrl/Cmd+Shift+V` 直插纯文本原文。
7. **抢占兼容** —— 审批/提问/子代理等内置面板仍能正常抢占输入区，切换后草稿幸存。
8. **卸载回落** —— 禁用/卸载插件后输入区回落为内置输入区，无渲染残留。
