# 0.2.0-alpha.2 发布验收清单

- 版本: `dsh-markdown-input@0.2.0-alpha.2`
- 内核线: `@deepseek-ai/dsh` `0.2.0-rc.x`（桌面端 `0.2.0-rc.2` 内核）
- 依据: [ADR-0004](../adr/0004-npm-release-remote-feedback-loop.md)；架构依据 [ADR-0003](../adr/0003-native-composer-paint-layer.md)
- 性质: **原生输入区转型版** —— 按 ADR-0003 退役 composer 接管链，转为「原生输入区 + 分层增强」；本版交付用户消息/steering 消息的 Markdown 投影与 #14 粘贴转 Markdown（L3）
- 说明: 输入区实时渲染暂缺（L1 绘制层随 #15 回归）；清单由 alpha.1 清单按原生架构改写

## 清单

1. **搜索与安装** —— 官方桌面端插件管理 UI 能搜到 `dsh-markdown-input`，安装/升级到 `0.2.0-alpha.2` 成功。
2. **原生输入区** —— 输入区保持宿主原生形态：无接管、无渲染/源码模式按钮（实时渲染暂缺属预期，勿记失败）。
3. **用户消息投影** —— 已发送的用户消息在聊天记录中按 Markdown 渲染，消息内容不被破坏，宿主产生的引用 chip 不被画坏。
4. **steering 投影** —— 回合运行中排队追加的消息，被吸收后的正式气泡按 Markdown 渲染。
5. **粘贴转换** —— 从网页/Word 复制富文本（标题、列表、链接、粗体），粘贴后自动变为干净 Markdown，无 HTML 残留。
6. **插入与撤销** —— 转换内容插入在光标处；粘贴后一步撤销（Ctrl/Cmd+Z）即还原到粘贴前。
7. **纯文本直插** —— 同样内容按 `Ctrl/Cmd+Shift+V` 粘贴，得到纯文本原文，不经转换。
8. **不干扰与回落** —— 纯文本、文件、图片粘贴行为与内置一致；禁用/卸载插件后一切回落原生，无残留。
