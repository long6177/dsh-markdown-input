# 0.2.0-alpha.7 发布验收清单

- 版本: `dsh-markdown-input@0.2.0-alpha.7`
- 内核线: `@deepseek-ai/dsh` `0.2.0-rc.x`（桌面端 `0.2.0-rc.2` 内核）
- 依据: [ADR-0004](../adr/0004-npm-release-remote-feedback-loop.md)；[ADR-0005](../adr/0005-composer-revival.md)
- 性质: **停止半件补齐** —— alpha.6 真机复测确认运行中无任何停止入口（#18 M3 ④ 未竟半件），本版按钉住的 rc.2 InputBar 语义补齐 #32：普通会话 `primaryStops` 主钮变停 + 可续子会话专属停止钮，取消走会话域 `conversation.cancel`、队列保留；Esc-Esc 快捷键为可选项未做
- 验收基准: 条目与 [alpha.6 清单](0.2.0-alpha.6-checklist.md) 相同；第 6 条为 #32 复测主项（alpha.6 时该条「运行中无停止按钮」转新票）

## 清单

1. **搜索与升级** —— 官方桌面端插件管理 UI 能搜到 `dsh-markdown-input`，升级到 `0.2.0-alpha.7` 成功；输入区变为接管卡。
2. **编辑手感** —— 编辑器可输入，焦点、中文输入法、Enter 发送 / Shift+Enter 换行正常；草稿跨页面刷新幸存。
3. **实时渲染** —— 粗体/斜体/行内代码/删除线以真样式呈现、语法标记淡显；光标行保留标记、移开折叠；渲染/源码模式开关可用。
4. **`+` 命令菜单** —— 左下角入口为 `+`（非曲别针）；添加/指令两分节八条目齐全；goal/plan 插入 claim token 后回车正确触发；file 条目添加附件不回退。
5. **权限与模型 pill** —— 权限预设三档切换生效、完全权限有确认门；模型/推理等级切换生效。
6. **发送/停止/排队（#32 复测主项）** —— 空闲可发送；**运行中且草稿为空：主按钮变「停止生成」，点击即中断在气回合，停止后回落「发送」**；运行中草稿有内容时主按钮保持发送语义（对齐原生 rc.2——该状态原生亦无停止钮，原生走 Esc-Esc，本卡未做）；排队追加后卡内可见排队条目、撤回/编辑/改向可用，**点击停止后排队条目仍在**。
7. **附件与粘贴** —— 附件上传/移除正常；富文本粘贴转干净 Markdown，`Ctrl/Cmd+Shift+V` 纯文本直插。
8. **chip 全量与补全弹层** —— `@` 文件、`/` 技能、会话引用以 chip 呈现并发送后宿主正确识别；输入 `/`、`@` 弹出补全弹层可选可插。**已知残留（不阻塞本版，勿重复转票）**：弹层中 model/plan/feedback/goal 行点击无反应（#28）；已发送用户气泡无复制行（#33）；plan chip 随原生 bar 结构性丢失、goal bar 未出现（#34）。观察项：如触发降级，出现一次性非模态提示、原生输入区顶上、草稿幸存。
