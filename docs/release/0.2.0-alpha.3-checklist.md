# 0.2.0-alpha.3 发布验收清单

- 版本: `dsh-markdown-input@0.2.0-alpha.3`
- 内核线: `@deepseek-ai/dsh` `0.2.0-rc.x`（桌面端 `0.2.0-rc.2` 内核）
- 依据: [ADR-0004](../adr/0004-npm-release-remote-feedback-loop.md)；架构依据 [ADR-0003](../adr/0003-native-composer-paint-layer.md)
- 性质: **绘制层首航版** —— 交付 #15（L1 核心）：输入区行内四件套实时着色、语法标记淡显；纯绘制、零 DOM 修改，发送文本保持原始 Markdown 源码
- 说明: 颜色与淡显强度为首个真机基线，观感偏差属预期、可下版微调；块级样式（代码块背景/标题/列表符号）随 #16 回归

## 清单

1. **搜索与安装** —— 官方桌面端插件管理 UI 能搜到 `dsh-markdown-input`，安装/升级到 `0.2.0-alpha.3` 成功。
2. **行内四件套** —— 在输入区键入 `**粗体**`、`*斜体*`、`` `行内代码` ``、`~~删除线~~`：闭合瞬间内容出现区分色，两侧语法标记变淡但仍可见、可编辑。
3. **实时跟手** —— 补全或删掉一侧标记，着色/淡显即时跟随，无需回车或切换预览；多个片段互不干扰，上一行未闭合的标记不会误染下一行。
4. **编辑零干扰** —— 中文输入法打字、光标移动与选区、撤销（Ctrl/Cmd+Z）手感与原生一致；着色不影响选中与删除。
5. **发送保持原文** —— 带 `**粗体**` 等标记的消息发送后，气泡按 Markdown 正常渲染，标记字符不丢失（发送的仍是原始源码）。
6. **非语法文本不受扰** —— 普通文字、`2 * 3 * 4` 一类算式、`snake_case` 下划线词、URL 不被误着色；`\*` 转义的星号保持字面。
7. **既有能力无回归** —— 富文本粘贴转 Markdown（含 `Ctrl/Cmd+Shift+V` 纯文本直插）、用户消息/steering 投影与 alpha.2 行为一致。
8. **回落干净** —— 禁用/卸载插件后输入区完全回落原生，无任何着色残留；新开会话输入区不损坏。
