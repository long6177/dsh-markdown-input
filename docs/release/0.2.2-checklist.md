## 清单

1. **发送与键位生命周期（主项，#74）** —— 快速连按/长按 Enter 只发一条；点工具栏任意按钮（发送/模式/`+`/pill）后不用重新点编辑区即可继续键入；发送成功后 Ctrl/Cmd+Z 不把已发文本复原回编辑器；中文 IME 候选确认的 Enter 不误发送；会话切换后编辑器自动聚焦。
2. **提交策略与 claim 通路（主项，#79）** —— 设置「忙碌时回车」偏好切到「插话发送」后，任务运行中 Enter 直接插话（默认「排队」则排队）；发送按钮文案显示「排队发送/插话发送」；空稿 Ctrl/Cmd+Enter 一键插话全部排队消息（占位提示同现）；`+` 菜单选「目标」等带参命令进入 claimed 阶段（幽灵提示出现）、Enter 正常提交。
3. **消息面与附件装配（主项，#77）** —— 多附件消息按原始交错顺序渲染（图片不再前置重排）、多图按 compact 瓦片、文件卡带扩展名徽标+大小；发送瞬间 echo 与正式气泡无样式跳变；附件栏上传中显示进度、缩略图点击可预览；排队条渲染缩略图与文件 chip。
4. **引用系统（主项，#75）** —— `@` 补全列表含会话/子代理会话，选中插入会话 chip；已发消息中 `@文件` chip 可点开侧栏预览（失败可重试）、`/技能` chip 打开源码；粘贴 API key/JWT 后气泡内掩码显示、可显隐切换；引用会话的消息下方出现「引用会话 · …」摘要行。
5. **补全弹层鲁棒性（#76）** —— 弱网/失败时 `/` 弹层不卡死（键盘可用、可重试、全空自动关）；某候选组还在 pending 时 Enter 不被吞；重连/预设切换后命令目录自动恢复真实目录；子代理会话 `+` 菜单不泄漏命令/技能行。
6. **预设与工作区（#78）** —— 开发者工具关闭时预设菜单不出现 PTC/Minimal；重连后预设名单自动刷新；工作区切换被拒时标题 chip 正确回滚；工作区面不可用时预设座位照常可用。
7. **低严重度清扫抽查（#80）** —— 会话 removed/父级离线等锁定态编辑器锁住；超限图片选取时即拒（不进附件栏）；长草稿内滚轮到顶/底后链给会话滚动；`@` 目录钻取有面包屑可逐级返回；goal 编辑 Shift+Enter 换行；停止按钮 tooltip 带 Esc+Esc。
8. **回归基准** —— 0.2.1 清单通过项不回退：键位恒发送与续行、渲染与模式切换、抢占与降级、视觉与文案随语言切换。
