- 版本: `dsh-markdown-input@0.2.3`

- 验收基准: [0.2.2 清单](0.2.2-checklist.md)通过项全部不回退；第 1–3 条为本轮主项（即 0.2.2 轮的三个失败项）

## 清单

1. **预设菜单姿态（主项，#82）** —— 已开始的会话（有历史消息）接管卡卡顶**不再出现**预设菜单（整条 hero 行与原生一致缺席）；新开/空白会话照常出现；工作区面缺席时预设座位仍独立出现。
2. **弹卡交互救活（主项，#83）** —— 模型 chip 打开的弹卡,「模型」「推理等级」两行**可点开子菜单**（模型列表/等级列表）;`+` 菜单点「模型」**正常开出**模型弹卡;#74 的工具栏点击后不丢焦点行为不回退。
3. **claim 单份插入（主项，#84）** —— `+` 菜单点「目标/计划」只出现**一个**命令 chip,随后进 claimed 阶段、幽灵提示正常、Enter 可提交;非空草稿中段选带参命令只替换该段、尾部文本保留。
4. **回归基准** —— 0.2.2 清单其余通过项不回退：发送与键位生命周期、提交策略（忙时偏好/加速键/按钮文案）、消息面装配、引用系统、补全鲁棒性、预设刷新/回滚、低严重度清扫抽查。
5. **工具行焦点** —— 工具行按钮（发送/模式/`+`/pill）点击后仍无需重新点击编辑区即可键入（#83 守卫不得误伤 #74 行为）。
