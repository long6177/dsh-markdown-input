## 清单

1. **升级与承载** —— 插件管理升级到 `0.2.0-alpha.19` 成功；输入区接管卡正常出现。
2. **列表只做一级（#55 主项）** —— 光标外：圆点/序号可见；列表行整体只**小幅内缩**（与正文有区分即可，不再是一个身位）；无嵌套层级视觉（贴入的多级源码同一档呈现）；折行对齐内容起点；`1.` 连写显示 1. 2. 3.、`1)` 后缀保留。
3. **Tab 无编辑器绑定（#55 主项）** —— 列表行或正文上按 Tab：**不改动文档**，走浏览器默认焦点移动（与源码模式一致）；不再有缩进/降级捷径。
4. **气泡列表续行贴左（#55 主项）** —— 发送 `1. 你好 / 2. 我是 / asdfa`：续行 `asdfa` 贴在气泡文本左缘、条目文本（你好/我是）在它右面一档；多行普通文本仍逐行保真（围栏代码块内部不改写、复制无尾随空格）。
5. **列表键位回归** —— Shift+Enter 空列表项/空引用行退出（无残留、无空行）、非空续行（标记沿用 / 序号+1 / 引用补 `> `）；Enter 在列表/引用/惰性续行行上恒发送。
6. **其余回归** —— 代码块首尾围栏折叠 + 语言浮标 + 光标自由进出；任务清单 checkbox 点击切换（Ctrl+Z 一步回）；`---` 水平分隔线；chip 弹层、粘贴转换、渲染/源码切换（undo 与滚动保持）、工具行/pill/量表不回退。
7. **源码模式纯净** —— 无装饰、无列表键位行为、原文对照。
8. **长文档手感** —— 200+ 行多列表多代码块输入无明显延迟。
