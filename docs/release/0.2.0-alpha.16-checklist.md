## 清单

1. **升级与承载** —— 插件管理升级到 `0.2.0-alpha.16` 成功；输入区接管卡正常出现。
2. **列表全件（#46 主项）** —— 光标外：`-`/`*`/`+` 折叠为同一圆点；`1.` 连写显示 1. 2. 3.（`1)` 后缀沿用源码写法）；嵌套列表层级缩进、子项独立计数；折行对齐内容起点（悬挂缩进）；Tab/Shift-Tab 列表行内 2 空格缩进/反缩进、列表外不拦截焦点；Shift-Enter 在空列表项/空引用行上退出（无残留标记、无多余空行）、在列表项/引用行续行（标记沿用 / 序号+1 / 引用补 `> `）。
3. **Enter 严格恒发送（#46 行为变更，重点体验）** —— 未闭合代码围栏内 Enter 直接发送（不再换行）；IME 组合期 Enter 不发送不换行；命令行文本仍走命令路由。
4. **代码块观感（#47 主项）** —— 光标外首尾围栏行整行不可见、无残留空行；块右上角只读语言浮标显示信息串首词（`​```ts title="x"` 整行隐藏、浮标只显 `ts`）；空代码块无浮标；光标入块首尾围栏原文还原、浮标消失，离开恢复。
5. **渲染小件（#48 主项）** —— 点击任务清单 checkbox 原地切换 `[ ]`↔`[x]`，Ctrl+Z 一步回切换前；hover 有克制可点暗示；`---`/`***`/`___` 光标外折叠为水平细线；setext 二级标题下划线不误渲染。
6. **键位与交互回归不丢** —— 菜单打开时 Tab/Enter/方向键仍先走菜单；粘贴富文本转 Markdown、chip 弹层、渲染/源码切换（undo 与滚动保持）、工具行、pill、排队条、量表、会话统计对话框等 alpha.15 通过项不回退。
7. **源码模式纯净** —— 切到源码模式：无任何新装饰、无列表键位行为、样式回归原文对照。
8. **长文档手感** —— 200+ 行、含多层列表与多个代码块的文档输入无明显延迟（#47 性能钉 200 块重建 101–128ms 的真机对照）。
