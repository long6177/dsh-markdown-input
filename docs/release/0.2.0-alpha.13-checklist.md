## 清单

1. **升级与承载** —— 插件管理升级到 `0.2.0-alpha.13` 成功；输入区接管卡正常出现。
2. **模型 pill 行预算（#39 复测）** —— 原生会显示模型名的窗宽下，接管卡 pill 显示「模型名 · 思考强度」；行更紧时**思考强度先消失、模型名后缩**（两级收缩）；模式钮为 22×22、字形与 `+`/attach 一致；提交钮形态与 tooltip/aria 不回归。**如实记录**：与原生完全同阈还差 ≈28px 结构盈余（模式座位），若个别窗宽仍「原生显示/插件折叠」，记下窗宽——清零需产品决策（隐藏模式座位或镜像原生嵌套行结构）。
3. **上下文量表（#43 复测）** —— 量表出现在接管卡**正下方**（圆环 + 百分比，深浅主题），卡不再贴窗口下边缘；点击开构成面板（系统/工具/对话分段、明细、紧凑数字）；无投影或无容量时整行不渲染（无幽灵占位）；模型切换致容量暂失时面板自动关闭。
4. **hero 行与 Agent 预设（#42 复测）** —— 新会话卡顶**工作区 chip 与预设 chip 同一行**（≈2px 间距）；预设菜单显示「标准模式 / PTC 模式 / 极简模式 / 创造模式」+ 灰色描述 + 当前行勾选，菜单锚定预设 chip 下方；键盘可达（Enter/Space 开、Escape 关）；切换被宿主拒绝时就地横幅（含预设名）；无可解析工作区时整卡虚线触发姿态不回归；老会话两个座位都不出现；**第一条消息仍在接管卡内发送**。
5. **卡面与拖放（#44 复测）** —— 拖动会话窗口期间占位符行区域**不再透明**；深浅主题下卡面底色与原生输入卡无肉眼差异；拖文件悬停遮罩四角不漏方角。
6. **回归不丢** —— alpha.12 已通过项不回退：编辑手感（焦点/IME/Enter）、实时渲染与源码开关、feedback 行直达、链式弹卡 token 消费、todo 面板（目标栏之前）、排队消息栏与撤回/编辑、发送/停止/排队、附件与富文本粘贴、`@`/`/` 弹层与 chip、气泡 Markdown 渲染与复制操作行、停用回落原生。
