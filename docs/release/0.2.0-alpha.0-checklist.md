# 0.2.0-alpha.0 发布验收清单

- 版本: `dsh-markdown-input@0.2.0-alpha.0`
- 内核线: `@deepseek-ai/dsh` `0.2.0-rc.x`（桌面端 `0.2.0-rc.2` 内核）
- 依据: [ADR-0004](../adr/0004-npm-release-remote-feedback-loop.md) —— 每次发版附带 ≤8 条验收清单，作为用户真机口头反馈的对照基准
- 说明: 本版本为占名版，由现有 v1 代码发布，仅用于打通「npm 发布 → 桌面端安装」入口；逐条口头反馈即可（通过/不通过 + 一句话现象），无需截图或日志

## 清单

1. **搜索与安装** —— 官方桌面端插件管理 UI 能搜到 `dsh-markdown-input`，安装 `0.2.0-alpha.0` 成功。
2. **实时渲染** —— 输入区变为 Markdown 实时编辑器：光标所在行语法标记可见，移开后折叠为样式呈现。
3. **模式切换** —— 渲染/源码模式可切换，重启会话后仍记住上次的模式。
4. **发送保真** —— 发送后模型收到的仍是原始 Markdown 源码（渲染只是视觉层，不改变提交内容）。
5. **用户消息投影** —— 已发送的用户消息在聊天记录中按 Markdown 渲染，@提及 与技能引用 chip 正常保留。
6. **粘贴转换** —— 粘贴富文本自动转为干净 Markdown；`Ctrl/Cmd+Shift+V` 直插纯文本原文。
7. **抢占兼容** —— 审批/提问/子代理等内置面板仍能正常抢占输入区，切换后草稿幸存。
8. **卸载回落** —— 禁用/卸载插件后输入区回落为内置输入区，无渲染残留。
