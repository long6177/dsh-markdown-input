2. **统计对话框（#43 主项）** —— detailed 模式下：
   - 表盘 pill 点击展开**「会话统计」**对话框：标题（表盘图标+会话统计）+ 分隔线 + 网格行——模型用时 / 工具调用用时 / 首 token 平均（TTFT）/ 输出速度（TPS），无数据的行不出现；

   - 交互与上下文量表构成面板同款：锚定 pill 上方、窄窗 12px 钳位、Escape / 点外关闭、**两面板互斥**（开一个关另一个）、再点同 pill 关闭；展开 pill 高亮；
   - 无任何计时数据时计数 pill 为静态（不可点）；纯输出会话用量 pill 退化为纯总量、无缓存命中行；
   - 深浅主题面板为菜单表面 + prominent 阴影。
