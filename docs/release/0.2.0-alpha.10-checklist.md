# 0.2.0-alpha.10 发布验收清单

- 版本: `dsh-markdown-input@0.2.0-alpha.10`
- 内核线: `@deepseek-ai/dsh` `0.2.0-rc.x`（桌面端 `0.2.0-rc.2` 内核）
- 依据: [ADR-0004](../adr/0004-npm-release-remote-feedback-loop.md)
- 性质: **用户气泡复制操作行（#33）** —— seat 替换丢掉了原生 `MessageIconActions`（复制/时钟行）。宿主组件不在公开 client 导出面，按原生形态重建：复制原始线上文本（Markdown 源码、chip 语法保留）、1 秒 ✓ 反馈、起始位时钟标签、hover 显现（复用宿主 `data-chat-flow-kind` 包裹层，最新一条常显）。同轮恢复 `userMessageCapability` 探测的 `apply()` 接线（#19 复活时丢失），探测面新增 copy-chrome 依赖，探测不通过回落原生 seat。
- 验收基准: 条目与 [alpha.9 清单](0.2.0-alpha.9-checklist.md) 相同；第 4 条气泡复制为 #33 复测主项

## 清单

1. **搜索与升级** —— 官方桌面端插件管理 UI 能搜到 `dsh-markdown-input`，升级到 `0.2.0-alpha.10` 成功；输入区变为接管卡。
2. **编辑手感** —— 编辑器可输入，焦点、中文输入法、Enter 发送 / Shift+Enter 换行正常；草稿跨页面刷新幸存。
3. **实时渲染** —— 粗体/斜体/行内代码/删除线以真样式呈现、语法标记淡显；光标行保留标记、移开折叠。
4. **气泡复制操作行（#33 复测主项）** —— hover 已发送用户气泡显现操作行（时间标签 + 复制按钮；最新一条常显、更早的 hover 显现、触摸设备常显）；点击复制**原始 Markdown 源码**（含 `@文件`/`/技能` chip 语法，非渲染产物）；成功图标切 ✓ 1 秒；排队 steering 气泡同样具备；暗色主题下按钮配色正常；Markdown 渲染与引用 chip 不回归。
5. **`+` 命令菜单** —— goal/plan/permission/model 行为回归正常（alpha.8/9 修复不回退）。
6. **发送/停止/排队** —— 运行中空草稿主钮变「停止生成」、点击中断在气回合；排队条目撤回/编辑/改向正常。
7. **附件与粘贴** —— 附件上传/移除正常；富文本粘贴转干净 Markdown。
8. **停用回落** —— 停用（或移除）插件后气泡回落原生 seat，原生复制按钮仍在；重新启用后 Markdown 气泡与复制行恢复。
