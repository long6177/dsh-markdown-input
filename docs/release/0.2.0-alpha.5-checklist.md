# 0.2.0-alpha.5 发布验收清单

- 版本: `dsh-markdown-input@0.2.0-alpha.5`
- 内核线: `@deepseek-ai/dsh` `0.2.0-rc.x`（桌面端 `0.2.0-rc.2` 内核）
- 依据: [ADR-0004](../adr/0004-npm-release-remote-feedback-loop.md)；[ADR-0005](../adr/0005-composer-revival.md) 与 [composer-revival.md](../plan/composer-revival.md)
- 性质: **chip 全量回归版** —— alpha.4 接管卡基础上，chip 全量（`@` 文件、`/` 指令+技能、会话引用 chips + 词典命中装饰）与补全弹层（#27/#28）、排队条（#30）随本版回归；并修复工具行①入口闩锁曲别针的缺陷（#29）
- 说明: 第 8 条尾为降级回落观察项：正常使用不触发，如遇宿主面缺失或渲染异常属预期降级路径

## 清单

1. **搜索与升级** —— 官方桌面端插件管理 UI 能搜到 `dsh-markdown-input`，升级到 `0.2.0-alpha.5` 成功；输入区变为接管卡。
2. **编辑手感** —— 编辑器可输入，焦点、中文输入法、Enter 发送 / Shift+Enter 换行正常；草稿跨页面刷新幸存。
3. **实时渲染** —— 粗体/斜体/行内代码/删除线以真样式呈现、语法标记淡显；光标行保留标记、移开折叠；渲染/源码模式开关可用。
4. **`+` 命令菜单（#29 修复复测）** —— 输入区左下角入口为 `+`（非曲别针）；点击展开 添加/指令 两分节、八条目齐全；goal/plan 插入 claim token 后回车正确触发；feedback/compact/export 直达执行；file 条目添加附件不回退。
5. **权限与模型 pill** —— 权限预设三档切换生效、完全权限有确认门；模型/推理等级切换生效。
6. **发送/停止/排队（#30）** —— 空闲可发送，运行中可停止；排队追加后接管卡内可见排队条目，支持撤回/编辑/改向。
7. **附件与粘贴** —— 附件上传/移除正常；富文本粘贴转干净 Markdown，`Ctrl/Cmd+Shift+V` 纯文本直插。
8. **chip 全量与补全弹层（#27/#28）** —— `@` 文件、`/` 技能、会话引用以 chip 呈现并发送后宿主正确识别；输入 `/`、`@` 弹出补全弹层可选可插；词典命中与 claim ghost 提示按规格显示；禁用/卸载插件回落原生无残留。观察项：如触发降级，出现一次性非模态提示、原生输入区顶上、草稿幸存。
