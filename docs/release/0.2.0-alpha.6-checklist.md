# 0.2.0-alpha.6 发布验收清单（热修复）

- 版本: `dsh-markdown-input@0.2.0-alpha.6`
- 内核线: `@deepseek-ai/dsh` `0.2.0-rc.x`（桌面端 `0.2.0-rc.2` 内核）
- 依据: [ADR-0004](../adr/0004-npm-release-remote-feedback-loop.md)；[ADR-0005](../adr/0005-composer-revival.md)
- 性质: **热修复版** —— alpha.5 真机复测发现 `remote` 命名空间取法错误（读裸服务属性而非 `remote.<ns>` 追踪服务），工具行①闩锁曲别针（#29）且 `@`/`/` chip 与补全弹层（#27/#28 面）在真机同样不可达；本版修正为点号服务取法并补齐 `commands.execute` 的 attachments 参数
- 验收基准: 条目与 [alpha.5 清单](0.2.0-alpha.5-checklist.md) 相同；第 4 条为 #29 复测主项，第 8 条 chip/弹层应真实可用（alpha.5 真机上为静默降级）

## 清单

1. **搜索与升级** —— 官方桌面端插件管理 UI 能搜到 `dsh-markdown-input`，升级到 `0.2.0-alpha.6` 成功；输入区变为接管卡。
2. **编辑手感** —— 编辑器可输入，焦点、中文输入法、Enter 发送 / Shift+Enter 换行正常；草稿跨页面刷新幸存。
3. **实时渲染** —— 粗体/斜体/行内代码/删除线以真样式呈现、语法标记淡显；光标行保留标记、移开折叠；渲染/源码模式开关可用。
4. **`+` 命令菜单（#29 复测主项）** —— 输入区左下角入口为 `+`（非曲别针）；点击展开 添加/指令 两分节、八条目齐全；goal/plan 插入 claim token 后回车正确触发；feedback/compact/export 直达执行；file 条目添加附件不回退。
5. **权限与模型 pill** —— 权限预设三档切换生效、完全权限有确认门；模型/推理等级切换生效。
6. **发送/停止/排队（#30）** —— 空闲可发送，运行中可停止；排队追加后接管卡内可见排队条目，支持撤回/编辑/改向。
7. **附件与粘贴** —— 附件上传/移除正常；富文本粘贴转干净 Markdown，`Ctrl/Cmd+Shift+V` 纯文本直插。
8. **chip 全量与补全弹层（#27/#28）** —— `@` 文件、`/` 技能、会话引用以 chip 呈现并发送后宿主正确识别；输入 `/`、`@` 弹出补全弹层可选可插；词典命中与 claim ghost 提示按规格显示；禁用/卸载插件回落原生无残留。观察项：如触发降级，出现一次性非模态提示、原生输入区顶上、草稿幸存。
