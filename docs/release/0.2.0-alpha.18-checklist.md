## 清单

1. **升级与承载** —— 插件管理升级到 `0.2.0-alpha.18` 成功；输入区接管卡正常出现。
2. **列表缩进观感（#53 主项）** —— 光标外：列表项**标记与内容整体**按层内缩一级（不再"标记贴边、只有内容缩进"），内容紧随标记；两级嵌套各进一层、层级清晰；折行对齐到内容起点；圆点与序号仍可见（连写 `1.` 显示 1. 2. 3.、`1)` 后缀保留）。
3. **Tab 降级（#53 主项）** —— 列表行内 Tab：当前行降一级成为上一同级项的子树（无序 2 空格、`1. ` 3 空格、`10. ` 4 空格，视觉立即下移一层）；列表首项按 Tab 无变化（无可降层级）；**列表外 Tab 不被拦截**（走焦点移动）；**Shift-Tab 不再作反缩进**（误缩进用 Ctrl+Z 撤销）；菜单打开时 Tab 仍先走菜单。
4. **用户消息换行保真（#54 主项）** —— 发送多行文本（含列表续行，如 `1. 你好 / 2. asdfao / afsdfa`）：气泡按行呈现、末行不再被并进列表项；围栏代码块消息渲染为代码块且内部不被改写（从气泡复制代码无尾随空格）；复制按钮仍给原始 markdown。
5. **列表与键位回归（#46–#52 不丢）** —— 圆点/序号可见、悬挂缩进折行对齐、Shift+Enter 空项退出/续行、Enter 严格恒发送（含列表/引用/惰性续行，围栏内发送）、IME 组合期吞键、代码块首尾围栏折叠与语言浮标、光标可自由进出块。
6. **其余回归** —— 任务清单 checkbox 点击切换（Ctrl+Z 一步回）、`---` 水平分隔线、粘贴转换、chip 弹层、渲染/源码切换（undo 与滚动保持）、工具行/弹层/pill/排队条/量表不回退。
7. **源码模式纯净** —— 切到源码模式：无装饰、无列表键位行为、原文对照。
8. **长文档手感** —— 200+ 行多列表多代码块输入无明显延迟。
