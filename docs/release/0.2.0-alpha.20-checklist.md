## 清单

1. **升级与承载** —— 插件管理升级到 `0.2.0-alpha.20` 成功；输入区接管卡正常出现。
2. **续行对齐（主项）** —— `1. afdasdf / 2. sdafs / asdfafd`（第三行顶格）：光标移开后三行文本同列，续行吸附内容列而非编辑区左缘；气泡里发 `1. 你好 / 2. 我是 / asdfa`：`asdfa` 与条目文本同列、序号悬在内容列左侧。
3. **空标记行键位（主项）** —— 空列表项 / 空引用行 / 空任务项 `- [ ] `：Shift+Enter = 清掉标记 + 光标落到新行（清出的空行留下）；Backspace = 原地清行、不换行；有内容的列表 / 引用 / 任务行 Shift+Enter 仍续项（序号+1 / `> ` / `- [ ] `）。
4. **分隔空格规则（主项）** —— `1.`、`-`、`>` 顶到行尾（还没敲空格）时整行保持原文、不折叠不内缩；敲下空格才长成列表/引用行；上一行是正文时 `1. ` 敲空格同样立刻缩进（`2. ` 保持原文，`- ` 归 setext 标题）。
5. **列表渲染回归** —— 一级内缩 0.5em、标记可见、折行与项内续行对齐内容起点、无嵌套层级视觉、Tab 无编辑器绑定。
6. **其余回归** —— 代码块围栏折叠 + 语言浮标 + 光标自由进出；任务清单 checkbox 点击切换（Ctrl+Z 一步回）；`---` 水平细线；气泡硬换行保真（围栏内不改写、复制无尾随空格）；chip 弹层、粘贴转换、渲染/源码切换、工具行 / pill / 量表不回退。
7. **源码模式纯净** —— 无装饰、无列表键位行为、原文对照（Shift+Enter 为普通换行）。
8. **长文档手感** —— 200+ 行多列表多代码块输入无明显延迟。
