# 0.2.0-alpha.11 发布验收清单

- 版本: `dsh-markdown-input@0.2.0-alpha.11`
- 内核线: `@deepseek-ai/dsh` `0.2.0-rc.x`（桌面端 `0.2.0-rc.2` 内核）
- 依据: [ADR-0004](../adr/0004-npm-release-remote-feedback-loop.md)
- 性质: **计划 chip 与目标栏（#34）** —— 接管卡替换整条链 fallback，原生 `conversation.input.plan` 座位与 `conversation.input.dock` 条（goal/todo/queue）随之结构性消失（dock 条渲染在链 fallback 内，issue 前提已修正）。按原生形态在卡内重建：工具行计划 chip（折叠目标值显示、点击经命令面执行 `/plan off`）、目标栏（相位/目标/暂停/继续/编辑/清除，activation 感知，CAS 动词走 `remote.goals`）、运行中占位符按原生 ladder 对齐（steerQueue → placeholder.plan → 卡片文案）。
- 验收基准: 条目与 [alpha.10 清单](0.2.0-alpha.10-checklist.md) 相同；第 4 条计划 chip/目标栏为 #34 复测主项，第 8 条补气泡复制不回归

## 清单

1. **搜索与升级** —— 官方桌面端插件管理 UI 能搜到 `dsh-markdown-input`，升级到 `0.2.0-alpha.11` 成功；输入区变为接管卡。
2. **编辑手感** —— 编辑器可输入，焦点、中文输入法、Enter 发送 / Shift+Enter 换行正常；草稿跨页面刷新幸存。
3. **实时渲染** —— 粗体/斜体/行内代码/删除线以真样式呈现、语法标记淡显；光标行保留标记、移开折叠。
4. **计划 chip 与目标栏（#34 复测主项）** —— `/plan on` 后工具行出现「计划」chip（含 `/plan` claim 未落定时），点击退出计划模式、chip 随投影消失；`/goal` 设置后输入条上方出现目标栏（排队栏之前），相位文案/目标内容/暂停/继续/编辑/清除可用，清除后消失；计划模式激活时占位符切「描述你的任务以生成计划」，运行中且有排队时切 steerQueue 文案；命令面或投影缺席时 chip 不出现、目标栏只降按钮不降可见性。
5. **`+` 命令菜单** —— goal/plan/permission/model 行为回归正常（alpha.8/9 修复不回退）。
6. **发送/停止/排队** —— 运行中空草稿主钮变「停止生成」、点击中断在气回合；排队条目撤回/编辑/改向正常。
7. **附件与粘贴** —— 附件上传/移除正常；富文本粘贴转干净 Markdown。
8. **停用回落与气泡复制** —— 停用（或移除）插件后回落原生输入区与气泡；重新启用后接管卡、Markdown 气泡与复制操作行（alpha.10 主项）不回归。
