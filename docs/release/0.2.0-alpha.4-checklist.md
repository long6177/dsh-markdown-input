# 0.2.0-alpha.4 发布验收清单

- 版本: `dsh-markdown-input@0.2.0-alpha.4`
- 内核线: `@deepseek-ai/dsh` `0.2.0-rc.x`（桌面端 `0.2.0-rc.2` 内核）
- 依据: [ADR-0004](../adr/0004-npm-release-remote-feedback-loop.md)；[ADR-0005](../adr/0005-composer-revival.md) 与需求落实文档 [composer-revival.md](../plan/composer-revival.md) §4.3 草稿定稿
- 性质: **接管卡复活版** —— v1 形态回归（`conversation.composer` 选举链低优先级接管 + 自带 CodeMirror 6 实时渲染编辑器），带两条硬化约束：error boundary 崩溃回落 + 逐面能力探测降级
- 说明: chip 全量（`@` 文件搜索、`/` 补全弹层、词典命中装饰）随 alpha.5（#27/#28）回归；alpha.4 chip 以纯文本透传保证正确性。第 8 条尾为降级回落观察项：正常使用不触发，如遇宿主面缺失或渲染异常属预期降级路径

## 清单

1. **搜索与升级** —— 官方桌面端插件管理 UI 能搜到 `dsh-markdown-input`，升级到 `0.2.0-alpha.4` 成功；输入区变为接管卡（回归预期）。
2. **编辑手感** —— 编辑器可输入，焦点、中文输入法、Enter 发送 / Shift+Enter 换行正常；草稿跨页面刷新幸存。
3. **实时渲染** —— 粗体/斜体/行内代码/删除线以真样式呈现、语法标记淡显；光标行保留标记、移开折叠；渲染/源码模式开关可用。
4. **`+` 命令菜单** —— 添加/指令两分节、八条目齐全；goal/plan 插入 claim token 后回车正确触发；feedback/compact/export 直达执行。
5. **权限与模型 pill** —— 权限预设三档切换生效、完全权限有确认门；模型/推理等级切换生效。
6. **发送/停止/排队** —— 空闲可发送，运行中可停止，可排队追加。
7. **附件与粘贴** —— 附件上传/移除正常；富文本粘贴转干净 Markdown，`Ctrl/Cmd+Shift+V` 纯文本直插。
8. **chip 透传与回落** —— `@` 文件、`/` 技能、会话引用以纯文本发送后宿主正确识别；禁用/卸载插件回落原生无残留；观察项：如触发降级，出现一次性非模态提示、原生输入区顶上、草稿幸存。
