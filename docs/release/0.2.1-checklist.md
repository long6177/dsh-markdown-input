# 0.2.1 发布验收清单

- 版本: `dsh-markdown-input@0.2.1`
- 内核线: `@deepseek-ai/dsh` `0.2.1-rc.x`（桌面端 `0.2.1-rc.2` 内核；peer `^0.2.1-rc.2`）
- 依据: [ADR-0004](../adr/0004-npm-release-remote-feedback-loop.md)
- 性质: **内核线 0.2.1-rc.2 适配首版 + 版本线转稳定**——去 alpha 后缀：功能面进入维护期，此后修复走补丁位（0.2.x）、功能走次版本位；宿主内核自身仍为 developer preview，兼容性仍以实测矩阵逐版本明示，稳定仅指本插件自身承诺。上游删除 `projectUserText` / `renderMessageImages` 后 chip 投影本地化、图片改走宿主 `conversation.chat.user.content` 工厂（#71）
- 验收基准: [0.2.0-alpha.20 清单](0.2.0-alpha.20-checklist.md)通过项全部不回退；第 1/2/3 条为本轮主项
- 记录: 结果写入 `outputs/retest-YYYYMMDD-0.2.1.md`（或顺延同名），确认的缺口就地开 issue

## 清单

1. **升级与承载（主项）** —— 0.2.1-rc.2 内核桌面端插件管理 UI 安装/升级到 `0.2.1` 成功；输入区接管卡正常出现（新内核下链式接管与「渲染」按钮/等宽编辑面仍生效）。
2. **用户消息投影（主项）** —— `@文件` / `/技能` / 会话引用 chip 在气泡中保留且周边按 Markdown 渲染（投影本地化后的行为应与 alpha.20 一致）；消息图片缩略图/预览走宿主图库、观感与原生一致；排队 steering 气泡同样渲染；引用 chip（@提及 / /技能 / 会话引用）在渲染结果中保留。
3. **katex 0.16→0.18 视觉抽查（主项）** —— 缺口依赖 katex 随上游 tag 跳大版本，单测不覆盖视觉：消息内数学/代码高亮无回归。
4. **键位回归** —— Enter 恒发送（围栏内也不发送）、Shift+Enter 换行（空标记行退出/Backspace 原地清行不回退）、中文 IME 候选 Enter 不误发。
5. **渲染与模式** —— 源码/渲染切换、F5 后模式持久化；`#` 标题折叠/恢复、`- [ ]` 复选框、列表续行对齐内容列不回退。
6. **附件与发送** —— 缩略图/文件 chip/× 删除/拖放入口；上传中扣住发送、失败 chip 与重试；断网发送错误横幅出现在接管卡上（约 6s 消散）。
7. **抢占与降级** —— 内置面板抢占后输入区恢复且草稿幸存；能力探测缺失面独立降级为原生输入区。
8. **视觉与文案** —— 圆角/菜单 backdrop/焦点环与宿主观感一致；界面切 English 按钮与占位文案随语言切换。
