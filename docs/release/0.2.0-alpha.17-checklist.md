## 清单

1. **升级与承载** —— 插件管理升级到 `0.2.0-alpha.17` 成功；输入区接管卡正常出现。
2. **列表标记可见（#50 主项）** —— 光标离开列表行后：`-`/`*`/`+` 行首**可见圆点**；有序行**可见序号**（连写 `1.` 显示 1. 2. 3.，`1)` 后缀沿用源码写法）；嵌套层级缩进与悬挂缩进（折行对齐内容起点）不变；发送文本仍为原始 markdown。
3. **Enter 严格恒发送（#51 主项，重点体验）** —— 在**非空列表行、引用行、列表/引用行紧随的下一行（无空行）**上按 Enter：直接发送、不插入换行；代码围栏内 Enter 发送（#46 语义）；IME 组合期 Enter 不发送不换行；菜单打开时 Enter 仍先走菜单（选中项）。
4. **代码块折叠（#52 主项，重点体验）** —— 光标外：首尾围栏行整行不可见、代码块上下**无残留空行**；右上角语言浮标在场（`​```ts title="x"` 只显 `ts`）；**光标可自由进出块**（上下方向键、点击），块内首尾围栏原文还原；在尾部 ``` 处 Shift+Enter 换行后编辑器响应正常（可继续输入、光标可动）；空代码块无浮标。
5. **列表/引用续行（#46 语义不回退）** —— Shift+Enter：空列表项/空引用行退出（无残留标记、无多余空行）；列表项续行（标记沿用 / 序号+1 / 引用补 `> `）；Tab/Shift-Tab 列表行内缩进/反缩进、列表外不拦截。
6. **回归不丢** —— 任务清单 checkbox 点击切换（Ctrl+Z 一步回）、`---` 等水平分隔线、shift+enter 通用换行、粘贴转换、chip 弹层、渲染/源码切换（undo 与滚动保持）、工具行/弹层/pill/排队条/量表等 alpha.16 通过项不回退。
7. **源码模式纯净** —— 切到源码模式：无装饰、无列表键位行为、原文对照。
8. **长文档手感** —— 200+ 行多列表多代码块输入无明显延迟。
