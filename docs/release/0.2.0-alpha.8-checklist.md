# 0.2.0-alpha.8 发布验收清单

- 版本: `dsh-markdown-input@0.2.0-alpha.8`
- 内核线: `@deepseek-ai/dsh` `0.2.0-rc.x`（桌面端 `0.2.0-rc.2` 内核）
- 依据: [ADR-0004](../adr/0004-npm-release-remote-feedback-loop.md)；[ADR-0005](../adr/0005-composer-revival.md)
- 性质: **弹层点击修复** —— alpha.6 真机复测发现弹层 model/plan/feedback/goal 行点击无反应（折入 #28）：根因为 claim 行应用时前导重检用了光标相对的 `isLeadingSelection()`，输入的触发 token 本身就在光标之前，守卫恒假静默丢弃；修复改为读活探针自身的 token 位置（宿主 beginCommand 规则），chain-open 失败不再写 dismissed 记忆；键盘/鼠标共用 pickRow 同享修复
- 验收基准: 条目与 [alpha.7 清单](0.2.0-alpha.7-checklist.md) 相同；第 8 条为 #28 复测主项

## 清单

1. **搜索与升级** —— 官方桌面端插件管理 UI 能搜到 `dsh-markdown-input`，升级到 `0.2.0-alpha.8` 成功；输入区变为接管卡。
2. **编辑手感** —— 编辑器可输入，焦点、中文输入法、Enter 发送 / Shift+Enter 换行正常；草稿跨页面刷新幸存。
3. **实时渲染** —— 粗体/斜体/行内代码/删除线以真样式呈现、语法标记淡显；光标行保留标记、移开折叠；渲染/源码模式开关可用。
4. **`+` 命令菜单** —— 左下角入口为 `+`；添加/指令两分节八条目齐全；goal/plan 插入 claim token 后回车正确触发；permission/model 行链式打开第二层弹卡；file 条目添加附件不回退。
5. **权限与模型 pill** —— 权限预设三档切换生效、完全权限有确认门；模型/推理等级切换生效。
6. **发送/停止/排队** —— 运行中空草稿主钮变「停止生成」、点击中断在气回合、停止后回落「发送」；排队条目可见、撤回/编辑/改向正常。
7. **附件与粘贴** —— 附件上传/移除正常；富文本粘贴转干净 Markdown，`Ctrl/Cmd+Shift+V` 纯文本直插。
8. **补全弹层（#28 复测主项）** —— 输入 `/` 弹出补全弹层：**claim 行（计划/目标/反馈）点击即在草稿头插入对应 claim token**（与 `+` 菜单一致）；**model 行点击打开模型选择弹卡**（与 `+` 菜单一致）；**键盘 Enter 选中与鼠标点击行为一致**；技能行选中插入、file 行附件选择、compact/export 直达执行回归正常；`@` 文件搜索与 Tab 下钻正常。已知残留（不阻塞本版，勿重复转票）：已发送用户气泡无复制行（#33）；plan chip 随原生 bar 结构性丢失、goal bar 未出现（#34）。
